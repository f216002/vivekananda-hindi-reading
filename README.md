# 辨喜文集第一卷・印地文讀書會

公開站：https://f216002.github.io/vivekananda-hindi-reading/

印地文版《विवेकानन्द साहित्य प्रथम खंड》（Advaita Ashrama，第三版 1989）第一批：掃描 PDF 1–30 頁，照書中順序做成句子卡。

## 卡片格式

一印地文句一卡：上印地文（天城體）、中羅馬拼音、下中文翻譯。
點播：中文 1 遍＋印地文 3 遍。音檔為 Azure Speech 預先合成的靜態檔，
每卡兩檔：`audio/{id}-zh.mp3`（中文）、`audio/{id}-hi.mp3`（印地文，播放時重播 3 次，不另存 3 份）。

- 中文：zh-TW-HsiaoChenNeural，溫柔語氣，放慢 20%
- 印地文：hi-IN-MadhurNeural（男聲），放慢 20%，不加 style
- 音檔格式：audio-24khz-96kbitrate-mono-mp3
- 音檔播不出來時，退回裝置語音（中文 zh-TW、印地文 hi-IN）
